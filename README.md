# Lyra

**مساعد صوتي مجاني ومفتوح المصدر يعمل على جهازك: صفّق مرتين أو نادِ "ليرا"، وتحكّم في الكمبيوتر بصوتك ويدك.**

> **English:** Lyra is a free, open-source desktop voice assistant with a cyan holographic HUD. Wake it with a double clap or its name, then control apps, volume, typing, screenshots and the mouse (with hand tracking). No API key required; smart answers come from a local [Ollama](https://ollama.com) model, with an optional Gemini key.

**الحالة:** نسخة تجريبية (beta). منطق الأوامر والواجهة مفحوصين، لكن الاستجابة للميكروفون والكاميرا تختلف من جهاز لآخر. أي مشكلة افتح لها Issue.

---

## المميزات

- **الاستدعاء:** تصفيقتين متتاليتين، أو ذكر الاسم ("ليرا" / "Lyra"). بعدها تكمّل كلامك بدون نداء جديد، وترجع للنوم لما تسكت.
- **واجهة هولوجرام:** نافذة بنواة ثلاثية الأبعاد سماوية، تتغيّر حركتها حسب الحالة (جاهزة، تسمع، تفكر، تتكلم).
- **التحكم في الجهاز:** فتح برامج ومواقع، بحث في جوجل ويوتيوب، كتابة بالصوت (عربي وإنجليزي)، التحكم في الصوت والموسيقى، لقطة شاشة، تمرير، تصغير وإغلاق النوافذ، قفل الجهاز.
- **التحكم بالماوس بيدك:** تتبع اليد بالكاميرا. قرصة بالسبابة = نقر، وبالوسطى = نقر يمين.
- **مؤقتات وملاحظات:** "ظبطي مؤقت 5 دقايق"، "تذكري إني أكلم أحمد".
- **ذكاء اصطناعي مجاني:** أي سؤال خارج الأوامر يُرسل إلى Ollama المحلي، بدون مفتاح API.
- **أمان افتراضي:** قائمة برامج مسموحة، إيقاف الجهاز معطّل، تأكيد قبل الأوامر الخطيرة، وسجل للأوامر.

## المتطلبات

- Python **3.10 أو 3.11** (مطلوب لمكتبة MediaPipe).
- ميكروفون، وكاميرا (للتحكم باليد فقط)، واتصال بالإنترنت (للتعرف على الكلام).
- اختياري: [Ollama](https://ollama.com) للردود الذكية المجانية.

## التثبيت

### Windows

```bat
git clone https://github.com/USERNAME/lyra-assistant.git
cd lyra-assistant
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

أو بنقرتين: شغّل `RUN_WINDOWS.bat` (بيثبّت المكتبات ويشغّل البرنامج).

### macOS

```bash
brew install portaudio python@3.11
git clone https://github.com/USERNAME/lyra-assistant.git && cd lyra-assistant
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### Linux (Debian / Ubuntu)

```bash
sudo apt install portaudio19-dev python3-tk python3-dev scrot xdotool espeak-ng
git clone https://github.com/USERNAME/lyra-assistant.git && cd lyra-assistant
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install "pywebview[qt]"      # أو ثبّت GTK: sudo apt install python3-gi gir1.2-webkit2-4.1
```

> على Linux يعمل التحكم بالماوس والكتابة تحت **X11**. بيئة Wayland تقيّد التحكم في الجهاز.

## الذكاء الاصطناعي المحلي (اختياري، موصى به)

```bash
# بعد تثبيت Ollama من ollama.com
ollama pull llama3.2
```

لو Ollama غير مثبّت، تعمل كل الأوامر عادي، وتتعطل فقط الإجابة على الأسئلة العامة. تقدر بدلًا من ذلك تضع مفتاح Gemini **مرة واحدة** في ملف الإعدادات.

## التشغيل

```bash
python lyra.py
```

أول مرة بتعمل معايرة للميكروفون لثانية، ثم تقول "ليرا جاهزة".

**التشغيل مع بداية Windows:**

```bat
python lyra.py --autostart
```

لإلغائه احذف الملف `lyra.bat` من مجلد Startup (`Win + R` ثم `shell:startup`).

## الصلاحيات

ليرا تعمل بنفس صلاحيات المستخدم الذي شغّلها. لا تحتاج صلاحيات مدير (Administrator)، ولا يُنصح بتشغيلها بها.

| الصلاحية | لماذا | كيف تمنحها |
|---|---|---|
| **الميكروفون** | سماع التصفيق والأوامر | Windows: الإعدادات ← الخصوصية ← الميكروفون ← اسمح لتطبيقات سطح المكتب. macOS: الإعدادات ← الخصوصية والأمان ← الميكروفون ← فعّل Terminal / IDE |
| **الكاميرا** | التحكم بالماوس باليد (اختياري) | نفس المسار تحت "الكاميرا" |
| **التحكم في الجهاز (Accessibility)** | تحريك الماوس والكتابة والاختصارات | macOS فقط: الخصوصية والأمان ← إمكانية الوصول (Accessibility) ← فعّل Terminal / IDE |
| **تسجيل الشاشة** | لقطة الشاشة | macOS فقط: الخصوصية والأمان ← تسجيل الشاشة |
| **الإنترنت** | التعرف على الكلام، وGemini لو فعّلته | لا يحتاج إذنًا خاصًا |

**ما تفعله ليرا:** تفتح برامج وروابط، تحاكي لوحة المفاتيح والماوس، تلتقط الشاشة، وتكتب في `~/.lyra` ومجلد Pictures فقط.
**ما لا تفعله:** لا تحذف أو تعدّل ملفات، ولا تنفّذ أكواد يولّدها الذكاء الاصطناعي، ولا ترسل ملفاتك إلى أي مكان.

## الإعدادات

يُنشأ الملف تلقائيًا في `~/.lyra/config.json`:

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `wake` | `both` | `clap` تصفيق فقط (محلي بالكامل)، `word` الاسم فقط، `both` الاثنان |
| `lang` | `ar-EG` | لغة التعرف على الكلام. يمكن `en-US` |
| `clap_level` | `0.30` | حساسية التصفيق. أقل رقم = أكثر حساسية |
| `wake_words` | `lyra, ليرا...` | كلمات الاستدعاء. أضف أي نطق يفهمه جوجل لاسمك |
| `allow_any_app` | `false` | `false` = فتح البرامج في القائمة المسموحة فقط |
| `allowed_apps` | `[]` | برامج إضافية مسموحة، مثل `["word", "firefox"]` |
| `allow_power` | `false` | السماح بإيقاف وإعادة تشغيل الجهاز (مع تأكيد) |
| `ollama_model` | `llama3.2` | نموذج Ollama المستخدم |
| `gemini_key` | `""` | اختياري، يُحفظ مرة واحدة |
| `voice_reply` | `true` | رد صوتي |
| `hand_preview` | `false` | إظهار نافذة الكاميرا مع التحكم باليد |

## الأمان والخصوصية

- **التصفيق** يُكتشف محليًا بالكامل ولا يُرسل أي صوت.
- **وضع "نادِ اسمي"** يرسل مقاطع الصوت المحيطة إلى خدمة التعرف على الكلام من Google. للخصوصية الأعلى استخدم `"wake": "clap"`.
- **أي صوت قريب** (فيديو، تلفزيون، شخص آخر) قد يشغّلها، لأنها لا تميّز صوتك. لذلك الأوامر الحساسة تطلب تأكيدًا أو معطّلة افتراضيًا.
- **مفتاح Gemini** يُحفظ نصًا عاديًا في ملف الإعدادات. لا تشاركه ولا ترفعه على GitHub (الملف خارج المستودع و`config.json` في `.gitignore`).
- **سجل الأوامر** في `~/.lyra/log.txt` (نص الأوامر فقط، بدون صوت).
- ثبّت المكتبات داخل بيئة `venv` كما في خطوات التثبيت.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| `PyAudio` لا يتثبت | Windows: استخدم Python 3.10/3.11. macOS: `brew install portaudio`. Linux: `sudo apt install portaudio19-dev` |
| التصفيق لا يُلتقط أو يُلتقط خطأ | عدّل `clap_level` (جرّب 0.2 أو 0.45) |
| لا تفهم "ليرا" | أضف النطق الذي تراه في الطرفية إلى `wake_words` |
| لا يظهر صوت عربي في الرد | ثبّت حزمة صوت عربية من إعدادات Windows ← اللغة ← الكلام |
| `pywebview` غير موجود | تعمل ليرا بدون النافذة. ثبّته بـ `pip install pywebview` |
| "مش في قائمة البرامج المسموحة" | أضف البرنامج إلى `allowed_apps` |
